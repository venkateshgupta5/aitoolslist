Legitimate, white-hat places to list aitoolslist.ai for backlinks + referral traffic.
Work top-down; the Tier-1 set carries the most authority. Submit with a consistent
description (reuse the one below) and the same logo each time.

**Canonical listing copy (reuse everywhere):**
> aitoolslist.ai — an independent, fortnightly AI-product intelligence publication.
> We research, fact-check and curate standout AI tools across 14 categories, with verified
> profiles, pricing, benchmarks and primary sources. Discover. Evaluate. Decide.

**Assets:** logo (`~/Desktop/aitoolslist-logo.png` / `-rounded.png`), URL `https://aitoolslist.ai`,
category = "AI directory / AI tools".

> Note: aitoolslist.ai is itself a curated AI-tools publication, so the best fits are
> **meta-directories** (directories *of* AI directories/tools), **launch platforms**, and
> **startup directories** — not niche single-tool catalogs. Verify each site is live and the
> link is dofollow before spending time; some flip to nofollow or paid-only.

## Submission workflow (keep it efficient)
1. Prep once: logo, 1-liner (above), longer description, screenshots, your email.
2. Do **3–5 submissions per day** (avoids looking spammy; keeps it sustainable).
3. Log each in a sheet: *Platform | URL | Date | Status | Dofollow? | Live link*.
4. After ~2 weeks, re-check that links went live; nudge any pending reviews.
5. Re-verify dofollow with a quick inspect — deprioritize nofollow-only sites.

## Don't
- No paid link farms, PBNs, or "buy 500 backlinks" gigs.
- Don't mass-submit identical spun text — vary nothing except where a field needs it.
- Don't submit to dead/parked directories just for a number.
